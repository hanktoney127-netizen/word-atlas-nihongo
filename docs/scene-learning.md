# 场景回想学习页

从“今日 → 开始今天的旅程”进入。开发时也可直接访问 `/#/learn`。

- 新卡、复习均先显示场景图和挖空例句；不再先展示完整词卡。
- 点图或“显示答案”揭晓；再次点图收起。两个操作均不记分。
- 揭晓时按设置朗读完整例句；仅四档自评提交 FSRS 并进入下一张。
- 中文提示、揭晓朗读、揭晓后假名可在右上角设置；设置和进度沿用原备份系统。
- 缺失例句或图片不会显示词语作为占位图，避免泄题。
- 旧版未完成的会话会迁移到场景流程，已评分词语不会重复计入。

## 日语内容字段

当前公开词库仍是原英语内容。本次不把英语数据机器翻译为日语。日语例句必须提供人工校对的 `parts`，为每个汉字词标注读音，明确活用后的挖空范围；不靠程序猜测读音。`en` 是沿用旧结构的字段名，也可存日语句子。

```json
{
  "en": "荷物を預かってもらえますか。",
  "zh": "可以帮我暂存一下行李吗？",
  "lang": "ja",
  "parts": [
    { "text": "荷物", "reading": "にもつ" },
    { "text": "を" },
    { "text": "預", "reading": "あず", "blank": true },
    { "text": "かって", "blank": true },
    { "text": "もらえますか。" }
  ]
}
```

有 `reading` 的片段揭晓后用原生 ruby 显示；所有片段拼接必须等于例句全文。多处 `blank` 会同时隐藏/揭晓。元数据无效时不会直接暴露答案。日语播放使用 `ja-JP`，没有录音时使用设备语音；设备是否具备日语声音需要实际试听。
